# Freedom FB Video
Progetto Android Studio con build APK tramite GitHub Actions.

## Compilazione
Apri Actions > Build Android APK > Run workflow. Scarica l'artifact Freedom-FB-Video-APK e installa app-debug.apk.

## Note
Usa solo contenuti pubblici o che sei autorizzato a salvare. La libreria yt-dlp integrata potrebbe richiedere aggiornamenti per seguire le modifiche di Facebook. I file sono salvati nella cartella privata dell'app (Android/data/com.freedom.fbvideo/files/Movies/Video). Questa versione è un prototipo non verificato su dispositivo; alcuni URL non funzioneranno.
